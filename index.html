설정 및 관리

홈 화면에 앱 설치

  1. 이 페이지를 Safari에서 엽니다.
  2. Safari의 공유 버튼(□↑)을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 웹 앱으로 열기를 켜고 추가합니다.

설치 후 홈 화면의 BM 아이콘을 누르면 주소창 없이 앱처럼 실행됩니다.

기존 기록이 중요하다면 설치 전 설정에서 데이터 백업을 먼저 받아두세요.

도움말

  • 선수 등록: 상단 '선수 등록 → 등록·관리'에서 '+ 개별' 또는 '+ 일괄'을 사용하세요.
  • 회원 불러오기: 상단 '선수 등록 → 참석자 선택'에서 회원을 검색하고 선택하세요. 회원 등록과 '현재 선수 명단 저장'은 '등록·관리' 탭에서 할 수 있습니다. 회원 수정·삭제는 명단의 '수정'에서, 다음 모임은 설정의 '회원에서 참석자 다시 선택'을 사용하세요.
  • 경기 통계: 상단 [통계]에서 전체 현황과 선수별 같은 팀·상대 팀 횟수를 확인할 수 있습니다.
  • 성별 구분: 파란색 선수 카드는 남성, 분홍색 선수 카드는 여성을 뜻합니다.
  • 대기실 빠른 조작: 상태별 인원을 눌러 목록을 좁히고, 검색 아이콘을 눌러 이름으로 선수를 찾으세요. 선수 카드를 누르면 대기실 아래에 휴식·복귀, 콕 냄, 정보 수정 버튼이 표시됩니다. 콕을 낸 선수는 이름 아래 ‘콕 냄’으로 표시됩니다.
  • 자동 매칭: 대기 중인 선수 4명을 배정합니다. 게임 중인 선수는 자동 매칭에 포함하지 않습니다.
  • 팀 구분: 네 선수를 코트 모양 테두리 안에 배치하고 중앙 구분선 양쪽으로 두 팀을 표시합니다.
  • 경기 유형: 코트가 진행 중이어도 자율·남복·여복·혼복 유형을 변경할 수 있습니다.
  • 수동 매칭: [수동] 버튼으로 4명을 선택해 배정합니다. 게임 중인 선수도 예약할 수 있으며, 빈 코트는 배정 후 [경기 시작]을 눌러 시작합니다.
  • 선수 교체: 배치된 선수 클릭 시 교체. 다음 대기에서는 게임 중인 선수도 선택할 수 있습니다.
  • 승계 기능: 다음 예약 선수가 다른 코트에서 게임 중이면 현재 경기만 종료하고 승계는 보류합니다.
알고리즘 우선순위
1. 매칭 기준(실제 경기 수 + 보정값)이 적은 순
2. 동률이면 최장 대기자를 보호하고 비슷하게 기다린 후보 중 반복 4인 조합·동반 출전을 줄임
3. 신규 참가자는 활동 선수 평균을 버림한 매칭 기준으로 시작
4. 혼복은 팀 급수 합 차이 최소화, 동률이면 최근 100경기의 파트너 중복 최소화
5. 일반 조합은 파트너 중복 최소화와 상위 두 명이 같은 팀인 경우 페널티 5 적용
조합을 섞기 위해 일부 선수는 한 차례 더 기다릴 수 있으며, 비교 비용이 같으면 오래 대기한 조합 우선
